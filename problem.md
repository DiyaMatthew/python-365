# Day 001 — Greeting Program

## Problem

Write a Python program that:

1. Asks the user for their name
2. Asks for their age
3. Prints a message like:

"Hello John! You are 25 years old. Welcome to Python 365!"

## Bonus Challenge

* Add one more question (e.g., favourite color)
* Include it in the final message

## 🎯 Goal

Understand how Python interacts with users:

* Taking input
* Printing output
* Formatting text
